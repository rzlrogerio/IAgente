# Projeto Python com investigar-code

Este workspace foi preparado para a macro `@investigar-code`.

## Diretrizes

- Trabalhe a partir da raiz Git atual e respeite as instrucoes especificas do repositorio.
- Priorize correcoes pequenas, testaveis e compativeis com a versao suportada do Python.
- Siga PEP 8, tipagem explicita quando trouxer valor, principios de minimo privilegio e tratamento seguro de dados.
- Nao exponha segredos em codigo, logs, relatorios ou comandos.
- Antes de editar, apresente a evidencia e a estrategia; depois execute a verificacao mais proxima do comportamento alterado.
- Nao instale dependencias nem execute comandos destrutivos sem autorizacao.

Para a revisao completa, invoque `@investigar-code`.
